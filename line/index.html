digdig / Line

A digdig micro app for the Mac

The ID you copied should open itself.

Line sits in the menu bar. Copy a ticket, a pull request, or a customer ID, then press the key you chose for that app. The browser opens the URL with the ID filled in.

Menu bar The key you choose Stays on your Mac

How it works

The clipboard already has the ID. Line’s job is the shortcut between that text and the right page.

1. Copy the ID

A Linear issue such as PROG-1482, a GitHub number, a Stripe customer, or a URL that already contains the ID.

2. Press the key

⌘L opens Linear. Each other app has its own key, and that key stays off until you turn it on.

3. The page opens

Line puts the ID into that app’s URL and opens it in the browser. A small note confirms which app and which ID.

A key for each app

Settings is a row per app: the shortcut, and a link you already have. Paste an issue, ticket, or customer page. Line reads the workspace, site, or repo out of that link and keeps {id} where the ID was. Linear is on. The other nineteen wait, so twenty global keys are not taken on the first launch.

Linear and Jira recognize a bare ID anywhere in what you copied. Most of the others look for their own URL or a short prefix, so a stray number stays put. ⌘L takes the browser address bar while Line is running. Change the key in Settings if you want that shortcut back.

It forgets, and it stays here

Five seconds after you open an ID, or sixty seconds if you never do, Line lets go of it. Copy the same text again and it is ready again. That countdown is Line’s memory. The clipboard itself is left as you left it.

The read happens on your Mac. Line does not send the clipboard anywhere, and it does not ask for Accessibility access. The shortcuts are registered with macOS directly.

Line is a digdig micro app. A menu bar fix for the ID already sitting on your clipboard.
